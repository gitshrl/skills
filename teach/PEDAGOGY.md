# Pedagogy

The learning theory behind every lesson in the workspace.

## Knowledge, skills, wisdom

Deep learning needs three things:

- **Knowledge**, captured from high-quality, high-trust resources
- **Skills**, acquired through highly-relevant interactive lessons devised by you, based on the knowledge
- **Wisdom**, which comes from interacting with other learners and practitioners

Before `RESOURCES.md` is well-populated, focus on finding high-quality resources which will help the user acquire knowledge. Never trust your parametric knowledge.

Topics weight these differently. Theoretical physics leans knowledge-heavy; yoga leans skills-heavy.

## Fluency vs storage strength

Two kinds of learning:

- **Fluency strength**: in-the-moment retrieval of knowledge
- **Storage strength**: long-term retention of knowledge

Fluency gives an illusory sense of mastery. Storage strength is the real goal. Build it through desirable difficulty:

- Retrieval practice (recall from memory)
- Spacing (distributing practice over time)
- Interleaving (mixing different but related topics; skills practice only)

## Difficulty is a dial, not a constant

For **knowledge acquisition**, difficulty is the enemy: it eats the working memory needed for understanding. Keep the knowledge in a lesson to only what the target skill requires.

For **skill acquisition**, difficulty is the tool: effortful retrieval is what builds storage strength.

## Zone of proximal development

Every lesson challenges the user 'just enough'.

When the user names an exact thing to learn, teach that. Otherwise find the zone by reading their `learning-records`, weighing what the mission demands, and teaching the most relevant thing that fits.

## Feedback loops

Teach skills through interactive lessons built on a feedback loop, where the user receives feedback on their performance. Keep the loop tight: immediate, and ideally automatic. Tools available:

- Interactive lessons using quizzes and light in-browser tasks
- Lessons guiding the user through real-world steps to take (for instance, yoga poses)

For quizzes, make each answer exactly the same number of words, and characters where possible. Formatting never hints at the answer.

## Wisdom comes from outside the workspace

Wisdom comes from true real-world interaction: testing skills outside the learning environment.

When a question appears to require wisdom, attempt an answer, then delegate to a **community**: a forum, a subreddit, a real-world class (budget permitting), a local interest group. Find high-reputation ones. If the user prefers not to join a community, respect it.
